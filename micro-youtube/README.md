# MicroTube 🎬

A modern YouTube-inspired video platform built as a portfolio project. The first release focuses on a polished responsive frontend experience and a clean architecture ready for a Node.js/API backend.

## Planned stack
- Frontend: React + Vite, modern CSS
- Backend: Node.js + Express REST API
- Database: MongoDB
- Authentication: JWT
- Media: Cloudinary or S3-compatible object storage
- Deployment: Vercel + Render/Railway

## Current MVP
The UI includes a responsive home feed, search, category navigation, video cards, shorts rail, subscription-style sidebar, watch-page concept, dark/light visual system, and mobile navigation.

## Product features roadmap
- User authentication and profiles
- Video upload and processing
- Likes, comments, playlists and subscriptions
- Watch history and watch-later
- Creator dashboard and analytics
- Search with filters
- Shorts vertical feed
- Notifications
- Moderation/reporting
- Personalized recommendation API
